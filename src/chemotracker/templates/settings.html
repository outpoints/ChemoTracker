How to get them on each phone
  1. Install ntfy from the App Store or Google Play.
  2. Tap +, then type this topic name exactly: {{ topic }}
  3. Leave the server as ntfy.sh unless you run your own. Do this on every phone that should get reminders.

Anyone who knows the topic name can read the reminders, so keep the long random name and don't post it anywhere. To keep medicine names off the ntfy server, turn off "Show medicine names".

More options
